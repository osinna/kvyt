# KVYT

Система бронювання квитків на події.

## Головне

`docs/kvyt-skeleton-spec.md` — технічне завдання. Воно головніше за припущення.
Прочитати повністю перед першим рядком коду. Порядок робіт — розділ 14,
зафіксовані рішення — розділ 15, критерії готовності — розділ 13.

## Межі поточної віхи

Робимо: `gateway`, `identity`, `catalog`, `booking`, `postgres`.
Не робимо: `payment`, `notify`, `broker`, `redis`, `jaeger`, `web`, Alembic, HTTPS.
Жоден дефект з каталогу `BUG_SCENARIO` не реалізовується — тільки механізм.

## Правила

- Мова коду, коментарів, логів і повідомлень API — англійська. Українською тільки README.
- Це система реального клієнта. Слів «навчальний», «курс», «студент», «завдання»
  в коді, README і повідомленнях помилок бути не має.
- Спільний код — у `libs/kvyt_common`, не копіюється по сервісах.
- Версії залежностей закріплені точно (`==`), не діапазонами.
- Не переходити до наступного пункту розділу 14, доки попередній не перевірений руками.
